## 📌 About Us

**DataNexus** is a student development team formed for the **CS3043 Database Systems Group Project**.

Our goal is to design and develop a complete database-driven system by applying the theoretical and practical concepts learned throughout the module.

The project will cover areas such as:

* Requirement analysis
* Database modelling
* Entity-Relationship diagrams
* Relational schema design
* Database normalization
* SQL implementation
* Constraints and data validation
* Backend and database integration
* User interface development
* Testing
* Project documentation

This GitHub organization contains the source code, database scripts, diagrams, documentation and other resources created throughout the project.

---

## 👥 Team

DataNexus consists of five undergraduate students from the Department of Computer Science and Engineering at the University of Moratuwa.

The responsibilities of each member will be assigned after the project requirements, system architecture and technology stack are finalized.
